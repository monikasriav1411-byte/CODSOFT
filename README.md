# CODSOFT Python Programming Internship

This repository contains the tasks completed as part of the CodSoft Python Programming Internship.

## Tasks Completed

### 1. Calculator
A simple Python calculator program that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

### 2. To-Do List Application
A Python-based To-Do List application that allows users to add, view, and manage tasks. Tasks are stored using a JSON file.

### 3. Contact List Manager
A Contact Management System developed in Python that allows users to add, view, search, and manage contact details. Contacts are stored in a JSON file.
